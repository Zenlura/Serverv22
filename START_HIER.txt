═══════════════════════════════════════════════════════════════
  🎯 SCHRITT-FÜR-SCHRITT ANLEITUNG
═══════════════════════════════════════════════════════════════

Schritt 1: Entpacke ZIP komplett
───────────────────────────────────────────────────────────────
→ Entpacke ALLE Dateien aus Dashboard_FIX_v3.zip
→ In dein Serverv22-dashboard Hauptverzeichnis
  (wo START.bat, STOP.bat, app/, frontend/ liegen)


Schritt 2: Passwort-Problem beheben
───────────────────────────────────────────────────────────────
→ RECHTSKLICK auf: PASSWORT_RESET.bat
→ "Als Administrator ausführen"
→ Neues Passwort setzen (z.B. "radstation")
→ Passwort aufschreiben! ✏️


Schritt 3: Diagnose (optional aber empfohlen)
───────────────────────────────────────────────────────────────
→ Doppelklick auf: START_DIAGNOSE_BLEIBT_OFFEN.bat
→ Prüfe ob alles ✅ ist
→ Fenster bleibt offen - lies die Meldungen!


Schritt 4: Fix ausführen
───────────────────────────────────────────────────────────────
→ Doppelklick auf: START_FIX_BLEIBT_OFFEN.bat
→ PostgreSQL-Passwort eingeben (von Schritt 2)
→ Warte bis "🎉 SETUP ABGESCHLOSSEN!" erscheint
→ Fenster bleibt offen!


Schritt 5: Server neu starten
───────────────────────────────────────────────────────────────
→ Führe aus: STOP.bat
→ Warte 5 Sekunden
→ Führe aus: START.bat


Schritt 6: Browser aufräumen
───────────────────────────────────────────────────────────────
→ Öffne Browser
→ Drücke: Strg + Shift + Delete
→ Lösche "Gecachte Bilder und Dateien"
→ Bestätige


Schritt 7: Dashboard öffnen
───────────────────────────────────────────────────────────────
→ Öffne: http://localhost:5173
→ Dashboard sollte jetzt funktionieren! 🎉

  ❌ IMMER NOCH PROBLEME?

Problem: "Als Administrator ausführen" funktioniert nicht
─────────────────────────────────────────────────────────────
Lösung: 
1. Windows + X
2. "Terminal (Administrator)" oder "Eingabeaufforderung (Admin)"
3. Navigiere zum Ordner: cd "C:\Pfad\zu\Serverv22-dashboard"
4. Führe aus: PASSWORT_RESET.bat


Problem: PostgreSQL-Dienst läuft nicht
─────────────────────────────────────────────────────────────
Lösung:
1. Windows + R
2. Tippe: services.msc
3. Suche: postgresql-x64-18
4. Rechtsklick → Starten


Problem: Fenster schließt sich trotzdem sofort
─────────────────────────────────────────────────────────────
Lösung:
1. Öffne Eingabeaufforderung (cmd)
2. Navigiere zum Ordner: cd "C:\Pfad\zu\Serverv22-dashboard"
3. Führe direkt aus: DIAGNOSE.bat
4. Oder: KOMPLETTER_FIX_VERBOSE.bat


Problem: "Datei nicht gefunden"
─────────────────────────────────────────────────────────────
Lösung:
→ ZIP wurde nicht komplett entpackt!
→ Entpacke nochmal ALLE Dateien
→ Prüfe ob diese Dateien da sind:
  - PASSWORT_RESET.bat
  - START_DIAGNOSE_BLEIBT_OFFEN.bat
  - START_FIX_BLEIBT_OFFEN.bat
  - fixed_dashboard.py
  - migration_vermietungen.sql
