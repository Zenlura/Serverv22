1️⃣  DATENBANK-TABELLE ERSTELLEN
═══════════════════════════════════════════════════════════════

Option A: Mit pgAdmin (GUI - einfach!)
---------------------------------------
1. Öffne pgAdmin
2. Verbinde zu localhost
3. Öffne Datenbank "radstation" (oder erstelle sie)
4. Rechtsklick auf "radstation" → Query Tool
5. Öffne die Datei: migration_vermietungen.sql
6. Klick auf den ▶️ Play-Button
7. Fertig!


Option B: Mit Kommandozeile (falls du das Passwort kennst)
-----------------------------------------------------------
Öffne CMD und tippe:

cd "C:\Program Files\PostgreSQL\18\bin"
psql.exe -U postgres

Dann im psql:
CREATE DATABASE radstation;
\c radstation
\i C:\Pfad\zu\deinem\Serverv22-dashboard\migration_vermietungen.sql
\q


Option C: Passwort vergessen? (komplizierter)
----------------------------------------------
Siehe POSTGRES_ANLEITUNG.md für Passwort-Reset


2️⃣  SERVER NEU STARTEN
═══════════════════════════════════════════════════════════════

1. STOP.bat ausführen
2. Warte 5 Sekunden
3. START.bat ausführen
4. Browser öffnen: http://localhost:5173
5. Ggf. Browser-Cache leeren (Strg + Shift + Delete)
